# Scope and verification limits

Linux host/target ABI, userspace and driver integration, service policy and staged runtime delivery.

The file verifier checks only its documented manifest format and listed regular-file hashes. It does not qualify a kernel ABI, boot path, active service or real DMA.

Use the checks appropriate to the requested change and report which were actually executed. Package contents are reusable procedures and helpers; they do not certify a new environment or target.
