# Optional mechanism routing

The core skill owns metric definitions, comparison validity and adoption reasoning. Discover a specialist only after identifying a relevant uncertain boundary; use supplied packages or the environment's available capability inventory.

| Evidence points to | Optional skill |
|---|---|
| Buffer starvation, copy lifetime, stale completion or drain | shared-buffer-lifecycle |
| Packet bursts, queue service or host transport limits | network-streaming-diagnosis |
| Same-input algorithm regression or a long processing stage | algorithm-porting-and-replay |
| Physical capture/display rate or scene validity | camera-hdmi-diagnosis |
| Linux runtime/backend or release/configuration mismatch | linux-runtime-and-release |
| Stream backpressure, packing or independent branch coupling | streaming-data-path-verification |

Do not load all specialists by default. If unavailable, use the core evidence method and report the missing mechanism-specific observation. Do not install a tool or run hardware simply to complete a preferred checklist. Specialist outputs feed the comparison; they do not recursively call this general skill.
