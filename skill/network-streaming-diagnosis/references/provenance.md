# Scope and verification limits

Physical link, network addressing, packet delivery, framed-input integrity, buffering and processing overload diagnosis.

A listening socket, printed IP or packet counter does not establish complete frames or correct processing. Representative load and end-to-end integrity need measured traffic.

Use the checks appropriate to the requested change and report which were actually executed. Package contents are reusable procedures and helpers; they do not certify a new environment or target.
